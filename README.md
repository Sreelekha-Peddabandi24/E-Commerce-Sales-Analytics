# 📊 E-Commerce Sales Analytics Project

## 📌 Project Overview

This project was completed as part of the **Data Analytics Internship Program at Primeor Solutions**.

The objective of this project was to analyze **E-Commerce sales data** using **Microsoft Excel, SQL, and Power BI**, generate meaningful business insights, identify performance trends, and develop an **interactive dashboard** to support data-driven decision-making.

---

## 🛠️ Tools & Technologies

- **Microsoft Excel** - Data cleaning, preprocessing, and analysis
- **SQL** - Business analysis and data querying
- **Power BI** - Interactive dashboards and data visualization
- **GitHub** - Project documentation and version control

---

## 📊 Dataset Information

- **Domain:** E-Commerce Sales
- **Records Analyzed:** **51,000+**
- **Data Includes:**
  - Orders
  - Customers
  - Products
  - Sales
  - Profit
  - Discounts
  - Regions
  - Markets

---

## 📈 Project Workflow

### 1️. Data Cleaning – Excel

The dataset was prepared for analysis by:

- Removed **duplicate records**
- Handled **missing values**
- Standardized **data formats**
- Corrected **data inconsistencies**
- Validated **numerical values**
- Prepared the cleaned dataset for further analysis

### 2️. Excel Analysis

The cleaned dataset was analyzed using Excel to identify:

- **Total Sales**
- **Total Profit**
- **Average Discount**
- **Top 5 Products by Sales**
- **Top 5 Loss-Making Products**
- **Region-wise Sales**
- **Category-wise Profit**
- **Segment-wise Sales**
- **Monthly Sales Trends**

### 3️. SQL Analysis

SQL queries were used to perform business-focused analysis, including:

- **Top 10 Profitable Products**
- **Top 10 Customers by Sales**
- **Region-wise Sales Analysis**
- **Category-wise Average Profit**
- **Highest Discount Category**
- **Orders with Negative Profit**
- **Monthly Sales Trend**
- **Market-wise Revenue Analysis**
- **Top Performing Sub-Categories**
- **Ship Mode Usage Analysis**

### 4️. Power BI Dashboard

Developed a **3-page interactive Power BI dashboard** to present key business metrics and insights.

####  Page 1 – Executive Overview

- **Total Sales**
- **Total Profit**
- **Total Orders**
- **Average Discount**

####  Page 2 – Sales Analysis

- **Sales by Region**
- **Sales by Market**
- **Monthly Sales Trend**
- **Category Performance**

####  Page 3 – Product & Customer Insights

- **Top Products**
- **Top Customers**
- **Profit by Sub-Category**
- **Segment Analysis**

---

## 💡 Key Business Insights

The analysis helped identify:

- **Top-performing products and customer segments**
- **Regional and market-wise sales performance**
- **Profitability across categories and sub-categories**
- **Loss-making products and negative-profit orders**
- **Discount-related profitability patterns**
- **Monthly sales trends**
- **Potential areas for business growth and improvement**
